# Light Cycle

> **Class project:** this game was built as a class project.

A Tron-themed take on Snake. You ride a light cycle around a 20×20 grid; the glowing light wall it leaves behind is the snake. Collect identity discs to score and grow your trail, and don't crash into the walls or your own light wall.

**Play it here:** https://jimmytaylor75.github.io/snake-code/

## Controls

| Key | Action |
| --- | --- |
| Arrow keys / WASD | Steer |
| Space | Start, pause, or ride again after a crash |
| P / Esc | Pause |
| M | Sound on/off |

## About

- One HTML file, no framework, nothing to install. Open `index.html` in any modern browser.
- Canvas rendering with a neon bezel inspired by the original Tron arcade game: Recognizers, a tank, the I/O tower, grid bugs and a disc duel.
- All sounds are synthesized live with the Web Audio API.
